# Sound credits

## Original clips: `sfx/`

Every clip in `sfx/` is original, made for Pass the Spark with jsfxr (https://github.com/chr15m/jsfxr, public domain under the Unlicense). No third-party audio. Each one is rendered from its recipe in `tools/sound/` (`npm run sounds`); see `tools/sound/README.md`.
